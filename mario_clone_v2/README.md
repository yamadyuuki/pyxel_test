# Mario Clone v2

Pyxelで作った横スクロールのマリオ風プラットフォーマーです。

## 機能概要

- **プレイヤー操作**: 左右移動、ジャンプ、しゃがみ。
- **物理/当たり判定**: 重力、床/壁との衝突、落下、コヨーテタイム、ジャンプバッファ、空中制御。
- **カメラ**: プレイヤー追従＋スムージング。
- **アイテム**: 宝石タイルに触れると自動回収（効果音あり）。
- **敵**: クリボー風の敵。上から踏むと撃破＆小ジャンプ、側面衝突でゲームオーバー。
- **リトライ**: `R`で即リセット。ゲームオーバー時は`Y`で再開、`N`で終了。
- **プラットフォーム**: 上から乗ると大ジャンプ（ジャンプ台）。横や下からは通常床として扱います。

## 操作方法

### 基本操作
- **移動**: `←` / `→`
- **ジャンプ**: `Space` または `↑`
- **しゃがみ**: `↓`（地上のみ）
- **ダッシュ**: `D` (移動中に押す)

### システム
- **ポーズ**: `P`
- **ゲームリセット**: `R`
- **ゲームオーバー時**: `Y`=リトライ / `N`=終了

### デバッグ
- **デバッグ表示**: `Q` (ON/OFF切り替え)

## 実行方法

前提として Python と Pyxel が必要です。

1) 依存のインストール

```bash
pip install pyxel
```

2) 実行

```bash
python main.py
```

## 技術仕様

- **エンジン**: Pyxel
- **画面解像度**: 256 x 256 ピクセル
- **フレームレート**: 60 FPS
- **マップサイズ**: 1024 x 256 ピクセル
- **タイルサイズ**: 8 x 8 ピクセル

## ファイル構成

- `main.py`: ゲームエントリ。ループ、カメラ、状態管理（PLAYING/GAME_OVER、リセット/リトライ）。
- `player.py`: プレイヤー挙動（移動/ジャンプ/しゃがみ、コヨーテタイム、ジャンプバッファ、当たり判定、宝石回収）。
- `system.py`: タイル取得・衝突判定・矩形移動・宝石収集ヘルパー群。
- `stage.py`: タイルマップ描画。
- `entity_manager.py`: 敵（クリボー）生成・更新・描画・衝突判定・リセット管理。
- `enemy.py`: クリボー風敵の挙動（左右移動、タイマーで向き反転）。
- `game_object.py`: 描画用ベースクラス。
- `constants.py`: 定数（重力・ジャンプ力・マップ/タイル設定・タイル種別・敵スプライト情報など）。
- `my_resource.pyxres`: 画像/タイルマップ/サウンドを含むPyxelリソース。

### タイル種別の目安（`constants.py`）

- **宝石**: 触れると自動回収し、タイルが消えます。
- **草/地面/足場**: 進入不可（床/壁）として衝突します。
- **ジャンプ台**: 上から乗ると大ジャンプします（横/下からは床扱い）。

## メモ

- 画面外下方向へ落下するとゲームオーバーです。
- カメラはプレイヤーを中心にスムージング追従し、マップ端でクランプします。
- リソース編集は Pyxel エディタで `my_resource.pyxres` を開いて行えます。
