# Mario Clone v2

Pyxelを使用したマリオ風プラットフォーマーゲーム。

## 実装機能

### 基本システム
- **プレイヤー制御**: 左右移動、ジャンプ、しゃがみ
- **物理システム**: 重力、衝突判定、落下制限
- **カメラシステム**: プレイヤー追従カメラ（スムージング付き）

### プレイヤー機能
- **移動**: 左右キーで移動（空中でも制御可能）
- **ジャンプ**: スペースキーまたは上キーでジャンプ
- **コヨーテタイム**: 地面を離れた直後でもジャンプ可能
- **しゃがみ**: 下キー長押しでしゃがみ（ジャンプ不可、移動速度低下）
- **頭上判定**: しゃがみから立ち上がる際の障害物チェック

### ゲーム要素
- **宝石収集**: プレイヤーが宝石タイルに触れると自動収集
- **効果音**: 宝石収集時の音響フィードバック
- **リセット機能**: Rキーでゲーム状態をリセット

### 技術仕様
- **エンジン**: Pyxel
- **解像度**: 256x256ピクセル
- **フレームレート**: 60 FPS
- **マップサイズ**: 512x256ピクセル
- **タイルサイズ**: 8x8ピクセル

## ファイル構成

- `main.py`: メインゲームループとカメラ制御
- `player.py`: プレイヤークラスと物理演算
- `stage.py`: ステージ描画管理
- `system.py`: 衝突判定とタイル操作システム
- `constants.py`: ゲーム定数とパラメータ
- `my_resource.pyxres`: グラフィックとサウンドリソース

## 操作方法

- **移動**: 左右矢印キー
- **ジャンプ**: スペースキーまたは上矢印キー
- **しゃがみ**: 下矢印キー
- **リセット**: Rキー

## 実行方法

```bash
python main.py
```
